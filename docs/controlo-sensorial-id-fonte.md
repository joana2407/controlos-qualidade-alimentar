# Fonte do controlo sensorial de I&D

Ficheiro de origem: `R-P5.10(01) Controlo Sensorial I&D.xlsx`, fornecido pela utilizadora.

O modelo usa avaliações de produto por provadores ao longo do tempo de vida, com momentos de referência apresentados para 3, 10 e 58 dias. Em cada avaliação, o registo inclui produto, data de produção/lote, validade pretendida, data da análise, tempo de vida e observações de I&D.

| Critério | Peso |
|---|---:|
| Aspeto geral | 10% |
| Fim de boca | 15% |
| Cor | 15% |
| Cheiro | 10% |
| Textura | 10% |
| Sabor | 40% |

Para cada critério, o ficheiro prevê vários provadores, média, moda, classificação parcial e percentagem de classificação final. O resumo compara os resultados por tempo de vida e regista a apreciação final do projeto.
